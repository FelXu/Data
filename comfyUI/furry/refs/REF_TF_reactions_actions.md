## 2. Reusable across species (mechanics library)

These transfer to Jack Anubis (or any bipedal TF) without copying end-species.

### 2.1 Clothing change pipeline (highest value)

1. **Seam stress lines** — white/light pull marks on fabric *before* tear (shirt pecs, jean thighs, waistband).  
2. **Snap / pop fasteners** — button/rivet flies off (`*PING*`, `*POP*`); zipper splits.  
3. **Horizontal shred** — shirt tears in laddered horizontal rips across chest/abs (J2–J3, D6, Muslekitty2, rubwulf, TF_comic_BlackRat).  
4. **Shoulder/sleeve first-fail** — deltoid expansion pops armhole before torso fully shreds (Zeroora2, ALM07, TF_comic).  
5. **Crotch / seat / fly blowout** — fabric fails at fly or seat as anatomy/hips expand (J4, D8 insets, Muslekitty4/6, rubwulf).  
6. **Tail-exit rip** — rear seam splits → vertical tatters as tail pushes through (J5/J6, D7, adoptawuff). For Jack: short tail through khaki rear.  
7. **Strap / rag cling** — after burst, fabric remains as **tight bands** around thick thighs/calves/ankles, or scraps hanging from shoulders (D5–D8, D12 ankle scrap, turned_up_to_11). Prefer **clinging rags mid-sequence**; Frame 8 Jack = all gone.  
8. **Fabric falling vs clinging** — jeans that fall intact after step-out (bedroom tanraak) vs shred-in-place (J/D/Black-rat). Jack sequence wants **shred-in-place** for drama on Frames 4–6.  
9. **Sneaker POP sequence** (canonical):
   - Toe bulge → claw punch-through front  
   - Heel-counter cracks as heel lifts (digitigrade)  
   - Sole separates / side splits  
   - White sock shreds to ankle rags  
   - Remnants hang as cuff or lie as debris  
   (Best refs: **D4–D5**, **J2/J5/J6**, ALM07, Muslekitty8, werefox sheet, Sparecustomes2 `*POP!*`)  
10. **Shirt pulled apart by hands** — character actively rips tee open when chest expands (J3, TF_comic center, **pokapikatf_002**). Distinct from passive burst.
11. **Staged underlayer fail** — outer shirt/jacket shreds first → bra/sports-top/undershirt still on → straps SNAP one-by-one → back band POP → center bridge tear → cups push aside → fall as waist rags (**ALM05/08/Muslekitty3** pattern; map bra→nothing for Jack male→♀ but keep *staged strap order* for tee seams).
12. **Belt / buckle projectile** — leather belt `*KRAK*` / buckle flies off before fly blowout (**pokapikatf_002/006**). Map to khaki shorts button/fly for Jack.
13. **Accessory cascade** — backpack straps, fingerless gloves, earbuds, glasses fail under shoulder/hand swell before main clothes finish (**pokapikatf_001**, Zeroora1, D6). Jack: glasses first; no backpack.
14. **Underwear show-through** — after fly/seat rip, underlayer visible stretched then tears (**ALM11** pink briefs through denim; **pokapikatf_004** green briefs). Jack: optional brief flash mid-F5 then gone.
15. **Thread-snap / fiber shear** — close-up of individual threads snapping over pecs before full RIP (`*CHRUT*`, `*SCRURP*` — **fkrystalbeast_015**). Strong mid-F4 detail.
16. **Debris-field aftermath** — sneakers shattered, sock heels, fabric triangles on floor as proof of prior burst (**ALM19/Muslekitty10**, pokapikatf_012, ALM17 STOMP). Jack F8 may show distant scraps, body nude.
17. **Muscle-vs-clothes involuntary flex** — growth forces double-bicep / chest-out pose that loads shoulder seams first (**Muslekitty1**). Useful F3–F4 posture without voluntary bodybuilding vibe.
18. **Costume/suit swap grammar** (Sparecustomes) — start in costume/suit → stress lines → shoulder `*CHUT*` claw-through → suit bands cling → full shred → optional second-form wings/fire (**NEG** wings/fire for Jack; keep suit→rag pipeline).

### 2.3 Reaction tropes (face / gaze / hands / posture)

- **Face:** wide eyes + open mouth (shock) → gritted teeth / eyes shut (strain) → half-lid tongue-out (overload) → roar with eyes shut (skull rewrite) → calm settled stare (end).  
- **Gaze targets:** hands → chest → crotch/shorts → feet/shoes → off-panel / inward (eyes shut) → own claws (power inspect). Rarely mirror in these packs.  
- **Hands:** wrist-grip → clutch forehead/stomach → tear shirt / pull fly → cup breasts → claw inspect / brace floor → hands-to-head during muzzle.  
- **Posture:** stagger → hunch → wide brace → arch → kneel/all-fours brief → digitigrade power stand/crouch.
- **Pacing grammar (ALM):** body shot → CU ear twitch → CU eye pinprick → CU claw/sleeve burst → return to roar — sell total-body process without showing every limb every panel.
- **Speech decay:** readable words → "HURRR"/"MURUH?" → pure roar/growl (ALM11–15, Muslekitty4–7). Jack: keep help-cry readable only through F7 energy, not literal lettering required.
- **Background emotion flash:** flat yellow/red radial behind face on shock panels (ALM12 bottom, Muslekitty) — optional prompt cue for F5–F7 intensity.
