# comfyUI

This folder holds shared ComfyUI assets for both furry and anime styles: workflows, prompts, and notes.

Furry and anime stay in this one repository and are not split into separate repos.

## Subfolders

Both styles live in this one project, under `comfyUI/`:

- `furry/` — Furry and Jack TF ComfyUI text and config: workflows, prompts, and notes.
- `anime/` — Anime-style ComfyUI assets beside furry. This folder is a stub for now.
